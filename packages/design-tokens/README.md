# design-tokens 🎨

Tasarımın temel değerleri: renkler (açık ve koyu mod), hesap türüne göre vurgu renkleri ve gradyanlar,
yazı stilleri, boşluklar, köşe yuvarlaklıkları, gölgeler.
**Profesyonel tasarım geldiğinde ilk değişecek yer burası.**

Hesap türlerinin vurgu renkleri: bireysel (yeşil-mavi), genç (pembe-mor), diyetisyen (mor-mavi),
eğitmen (turuncu-pembe), salon yöneticisi (mavi-mor), salon eğitmeni (sarı-turuncu).
