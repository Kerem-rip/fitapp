# components

Birden fazla ekranda kullanılan, uygulamaya özel parçalar. (Genel tasarım parçaları `packages/ui-mobile` içindedir.)

| Dosya | Ne işe yarar |
|---|---|
| `RoleTabs.tsx` | Her hesap türünün alttan yüzen sekme çubuğu |
| `AppHeader.tsx` | Ana sayfaların üst başlığı (avatar, bildirim, mesaj) |
| `AccountSection.tsx` | Görünüm, çıkış, hesap silme (30 gün geri dönüş) ve demo sıfırlama |
| `AppointmentSheet.tsx` | Randevu / ders ekleme penceresi |
| `ConfirmSheet.tsx` | Onay penceresi |
| `WeekStrip.tsx` | Haftalık gün şeridi |
| `ChipRow.tsx` | Seçim çipleri |
