# (auth)

Girişsiz ekranlar: karşılama (index), giriş (login), kayıt türü seçimi (register-type), standart kayıt (register),
profesyonel alan seçimi (pro-field), profesyonel kayıt (pro-register), e-posta kodu (verify) ve gizli yönetici girişi (admin-login).
Karşılama ekranında logoya uzun basınca bağlantı ayarı ve yönetici girişi açılır.
