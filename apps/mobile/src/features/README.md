# features

Ekranların asıl içeriği, özellik özellik. `src/app/` altındaki route dosyaları bunları çağırır.

| Klasör | İçerik |
|---|---|
| `home/` | Bugün (kullanıcı ana sayfası) |
| `nutrition/` | Öğün kaydı, kalori hesaplayıcı, örnek menü |
| `exercises/` | Egzersiz kütüphanesi |
| `discover/` | Uzman ve salon keşfi |
| `messages/` | Mesaj kutusu |
| `profile/` | Kullanıcı ve uzman profilleri |
| `pro/` | Diyetisyen ve eğitmen paneli, danışan listesi, programlar |
| `agenda/` | Randevu takvimi |
| `gym/` | Salon yöneticisi ve personel ekranları |
